# Single-Cell RNA-seq Bootcamp (Python)

> A hands-on learning journey through modern single-cell RNA sequencing analysis using Python.

## About

This repository documents my progress while learning the complete single-cell RNA-seq analysis workflow from scratch.

The goal is not only to reproduce existing pipelines, but to understand every concept, every algorithm, and every implementation detail behind modern scRNA-seq analysis.

The project is being developed incrementally, with each module building upon the previous one.

---

## Learning Philosophy

This repository follows several principles:

- Learn concepts before implementation.
- Understand *why*, not only *how*.
- Build everything step by step.
- Keep analyses reproducible.
- Write production-quality, well-documented code.
- Create a permanent knowledge base throughout the learning process.
